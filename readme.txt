# PFT Project Overview

In PFT, there are a total of 2 subdirectories:
- **PFT-2**: Implementation of the PFT algorithm.
- **src_replace**: Used to replace Pluto's core functionality to enable Pluto to generate the polyhedral information required by PFT.

## Prerequisites

Ensure your Python environment includes all required dependencies:
- `sympy`
- `numpy`
- `scipy`
- `argparse`
- (and any other necessary libraries).

## Usage Steps

1. Use `src_replace` to modify the core functionality of Pluto so that it can generate the polyhedral information required for PFT.
2. Use `PFT` to process the input polyhedron file for automatic generation of compute.
3. In `PFT-2/new_compute`, obtain the TVM kernel from the code automatically generated by PFT. Use TVM Ansor for automatic tuning to optimize the operator.
